Will this user miss a payment next month?

Synavo sits on top of a user's existing bank accounts. It watches bills and subscriptions, and if a payment is about to fail, it reroutes it through an account that has the money. This model estimates the probability that a user misses a bill or subscription payment next month, so Synavo can step in before the payment fails.

How it works

A logistic regression model trained on 5,000 synthetic Synavo users (seed 42, 70/30 stratified split). Test accuracy is about 0.73, with train and test scores close together, so the model is not overfitting.

VariableTypeEffect on risk
months_as_userDiscrete, 1 to 60Longer tenure lowers risk
avg_monthly_balanceContinuous, EUR 0 to 5,000Higher balance lowers risk
active_subscriptionsDiscrete, 0 to 15More subscriptions raise risk
missed_payment (target)Binary1 = misses a payment, 0 = pays on time

Risk levels: below 35% is low, 35% to 60% is medium, 60% and above is high.

API endpoint

Other apps can get the same prediction as JSON from /api/predict.

GET with query parameters

{{ request.host_url }}api/predict?months_as_user=6&avg_monthly_balance=450&active_subscriptions=9

POST with a JSON body

curl -X POST {{ request.host_url }}api/predict \
  -H "Content-Type: application/json" \
  -d '{"months_as_user": 6, "avg_monthly_balance": 450, "active_subscriptions": 9}'

Full documentation is in the GitHub README. A summary is at /api.
