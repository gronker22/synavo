# Adapted LLM prompt used to generate `fintech.py`

> Create a python code for a logistic regression using three columns data frame. First column discrete months as user, second column average monthly balance in euros as a continuous variable and third column number of active subscriptions as a discrete variable. Name all variables using Python style, small cap with undercore for spaces. Target variable binary missed payment or paid on time, representing whether a Synavo user misses a bill or subscription payment next month. Generate all variables randomly using numpy. Set the seed so that all variables always get the same value. Save the data to an excel named fintech.xlsx without index. Split the data into train and test. Validate the model using classification report in both train and test data. Dump the model into a file using joblib, call the file fintech.joblib.
